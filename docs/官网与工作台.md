# 通语官网与工作台

对外品牌为「通语 TongYu」，宣传语为「让每一次客户咨询，都有回应」。公司主体和联系方式暂不展示，不放置未经确认的价格、试用期限、客户案例或效果数字。

- `/`：轻量官网，源码位于 `apps/website`，无第三方运行时依赖。
- `/console/?surface=agent`：企业客服登录；企业标识、账号和密码沿用现有服务端认证。
- `/console/?surface=platform`：平台管理入口；与租户成员权限保持独立。
- 登录页的「返回通语官网」回到同域根路径；已登录成员正常恢复工作台。

官网不提供自助注册、在线购买或预约表单，开通方式说明与目前管理员建立企业账号的流程一致。工作台继续使用真实会话、成员和权限，不使用原型中的模拟数据。

## 本地验收

先运行现有本地业务服务，再构建 Flutter：

```powershell
powershell -File scripts/build-console.ps1
node scripts/preview-console.cjs
```

默认打开 `http://127.0.0.1:18765/`。官网与最新的 `apps/agent_console/build/web` 同源提供，API 与 WebSocket 默认转发到本机 8080 服务。预览本身不执行迁移、不重置数据；真实登录后的操作会访问本地业务服务。

可用 `PREVIEW_PORT`、`PREVIEW_API` 指定本机端口。退出预览进程即可停止预览。

## 打包

Dockerfile 将官网复制到 `/static/website`，Flutter 构建复制到 `/static/console`。服务端在配置 `STATIC_DIR` 后提供根路径官网；未知 API 和未知资源保持 404。隔离打包脚本同时包含官网源码。仅复制静态目录不能使旧版本服务端获得新增的根路径路由，发布时需要同时使用更新后的服务端。
