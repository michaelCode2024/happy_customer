# 消息提醒、未读与回执验收

> 历史专项记录：下文的实现和测试数量为原记录，不代表 2026-10-23 当前版本、线上部署或客户验收。本次审查只核对契约与文档，未重新执行这些历史测试；当前资料入口见 [文档索引](00-文档索引.md)。

2026-10-11，本机 `http://127.0.0.1:8080`，使用独立测试企业与客服/客户浏览器标签页；未发布生产。

## 已完成

- 客服设置包含新消息提示音、测试提示音、桌面通知开关；短时间连续消息合并，桌面提醒不显示客户正文。
- 开放 API 包含企业未读汇总、会话回执查询、已读及送达上报；read/write 权限与企业身份隔离。
- 已读使用正数 sequence，只前进；只读部分消息不会清空后续消息。客户端错误请求不清空角标，重复消息不重复计数。
- 客服设置页不自动已读，访客窗口收起或页面隐藏不自动已读；查看历史时暂停最新消息自动已读。
- conversation.read / conversation.delivered 可在后台订阅，与游标事务一起入队；接收方仍应验签和幂等。
- 回调表单校验及服务端保存失败保留输入、允许重试。

## 证据与结果

1. 实际客户浏览器发送消息，客服队列出现未读；停留在设置页时保持未读。
2. 未读 2 时，开放 API 上报 readSequence=5 后剩余未读 1；后台队列同步显示 1。再打开会话查看最后一条，未读变为 0。
3. 客服在浏览器回复，客户页面实时显示公开回复；双方最终 readSequence / deliveredSequence 均为 6，服务端未读汇总为 0。
4. 重复上报较早游标不会回退；sequence=0 返回 400，只读密钥写入返回 403，错误 readerId 和不属于密钥的会话查询返回 404。跨企业游标操作有数据库回归测试。
5. 真实 Docker 回调工作进程向本机接收服务器投递 23 次：已读 12 次、送达 11 次，数据库均为 SUCCEEDED，接收端全部通过 HMAC 签名校验。
6. 浏览器播放测试提示音；客户新消息触发音频播放。音频元素实际进入 playing 并播放至 ended / 0.2 秒。没有仅凭调用播放函数认定通过。
7. 浏览器回调表单输入错误地址时保持打开，错误和输入均保留；修改后出现“回调配置已保存”。已读/送达订阅选项可见。
8. 使用指南页面包含新接口、权限、凭证用途与签名去重说明。

Go `go test ./...` 通过（含真实 PostgreSQL 的回执与事务出队测试）；Flutter 46 项测试通过；Widget 13 项测试通过（含隐藏页面、重复事件与失败回执不清空未读）。服务端、Flutter Web 和 Widget 构建已更新到本机运行目录。

## 验收边界

内置浏览器没有允许桌面通知，已验证“浏览器未允许通知；提示音和未读角标仍可使用”的降级提示。操作系统通知实际弹出未验收。页面焦点/隐藏逻辑有客户端回归覆盖；内置浏览器同时把两个标签页报告为可见，不能据此认定真实后台标签切换已验证。原生 App 推送、浏览器关闭后推送、物理手机及生产部署不在本次范围。

临时客服已退出；测试企业/入口/账号和 Webhook 已停用，测试 API Key 已撤销，接收器停止，明文密钥与临时脚本已清理。保留测试消息和回执用于审计。
