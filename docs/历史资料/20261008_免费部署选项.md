# 2026-10-08 免费云部署选项原始记录

历史价格、配额与当时环境状态不代表当前可用性。不得作为生产承诺；现行部署入口为上级 deployment.md。

# 部署选择

## 开发验证：Northflank Sandbox

适用于没有服务器的开发与演示阶段。其[官方价格页](https://northflank.com/pricing)在 2026-10-08 列出：

- 2 个免费 Service
- 1 个免费 Database
- 2 个免费 Cron Job
- Always-on compute，不休眠
- 支持 Dockerfile、WebSocket、自动 HTTPS 和自定义域名

Northflank 的[计费文档](https://northflank.com/docs/v1/application/billing/pricing-on-northflank.md)明确指出 Sandbox **不应用于生产**。它不能作为真实客户的可用性、数据持久性和备份承诺；正式商用需要有 SLA、持久存储和备份的付费资源。

部署步骤：

1. 将仓库推送到 GitHub、GitLab 或 Bitbucket（当前仓库尚未配置远端）。
2. 在 Northflank 创建 Sandbox Project。
3. 创建 PostgreSQL Addon，取得平台提供的连接地址。
4. 从仓库创建 Service，构建类型选择项目根目录的 `Dockerfile`。该文件会分别编译 Go API、widget 单文件脚本和 Flutter Web，最终从同一个容器提供 `/widget.js`、`/h5/{inboxKey}`、`/console/`、API 与 WebSocket；不要只上传 Go 二进制。多阶段构建需要能访问 Docker Hub、ECR Public、GitHub Container Registry、gcr.io、npm 和 pub.dev。
5. 配置环境变量：
    - `DATABASE_URL`：PostgreSQL TLS 连接串
    - `PUBLIC_BASE_URL`：Service 的公开 HTTPS 地址（不能包含尾部斜杠；安装链接依赖它）
    - `WIDGET_TOKEN_SECRET`：至少 32 字符的随机密钥
    - `WIDGET_TOKEN_TTL=12h`
    - `PLATFORM_ADMIN_EMAIL`、`PLATFORM_ADMIN_PASSWORD`：首次启动创建平台账号；生产必须使用独立邮箱和强密码
    - `ALLOWED_ORIGINS`：托管客服组件的网站来源和客服后台来源，逗号分隔；不要在真实客户环境使用 `*`
    - `DEMO_ENABLED=false`
    - `STORAGE_DRIVER=local` 且上传目录挂载持久卷，或配置 `STORAGE_DRIVER=s3` 及 S3 兼容对象存储。容器文件系统本身是临时的，不能存客户附件。
    - `AI_PROVIDER`、`AI_API_KEY`、`AI_MODEL`：可选；不配置时 AI 为禁用状态，不能宣称 AI 自动回复可用。
6. 端口设置为 `8080`，健康检查路径为 `/health`。
7. 验收：访问 `/ready`、`/widget.js`、`/h5/<publicKey>` 与 `/console/`；用真实企业账号登录，并在独立域名嵌入组件，发送一条消息及附件，重启后确认附件仍可读取。

免费计划政策可能变化，创建资源前应再次查看官方价格页。当前没有仓库远端、Northflank 账号授权或生产密钥，因此上述资源**尚未创建**；本地构建通过不代表已经上线。

## 数据库备选：Neon Free

Neon 官方当前说明 Free 计划永久有效且无需信用卡，每项目包括 1 GB PostgreSQL 存储和 100 CU-hours；空闲 5 分钟自动休眠。将 Neon 的 pooled connection string 配到 `DATABASE_URL` 即可。

冷启动会影响客服首次连接，因此只建议开发验证。进入真实客户阶段应升级为不休眠的数据库与服务。

## 开源自托管方案

- Coolify：开源 PaaS，适合后续在自己的 VPS 上管理 Docker 服务、数据库、证书和发布。
- Dokploy：开源 Docker/PaaS 管理面板，定位类似。
- Supabase：PostgreSQL、认证、存储等组件可开源自托管，也提供云免费计划。

这些软件“开源”不代表“免费提供服务器”。有 VPS 后可选 Coolify/Dokploy；当前无服务器时先用托管免费额度更实际。

## 交付相关环境变量（并发 / 嵌入）

| 变量 | 默认 | 说明 |
|------|------|------|
| `DATABASE_MAX_CONNS` | `40` | PostgreSQL 连接池上限 |
| `MAX_WS_CONNECTIONS` | `10000` | 单实例 WebSocket 硬顶，`0` 不限制 |
| `FRAME_ANCESTORS` | `*` | `/h5` 的 CSP `frame-ancestors`，业务域名可写成 `https://app.example.com` |
| `ALLOWED_ORIGINS` | `*` | CORS / WS Origin |
| `STORAGE_DRIVER` | `local` | 多副本请用 `s3` |

指标：`GET /metrics`（Prometheus 文本）。就绪：`GET /ready` 含 `realtimeConnections`。业务系统 iframe 与 Open API 见 [integrations.md](../integrations.md)、[open-api.md](../open-api.md)。
