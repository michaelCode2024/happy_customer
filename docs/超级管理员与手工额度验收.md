# 超级管理员与手工额度

> 历史专项记录：下文的实现和测试数量为原记录，不代表 2026-10-23 当前版本、线上部署或客户验收。本次审查只核对契约与文档，未重新执行这些历史测试；当前资料入口见 [文档索引](00-文档索引.md)。

入口：本地 `http://localhost:8080/console/`，选择平台管理员登录。

平台后台提供平台概览、企业与账号、套餐与额度、操作记录、平台设置。企业额度列表支持搜索和分页，实际显示基础额度与本月追加额度合计及已用数量。

操作路径：选择企业 → 分配额度 → 选择修改每月额度或一次性追加 → 填写额度及调整说明 → 查看调整前后对比 → 确认分配 → 查看操作记录。基础设置还包含套餐、坐席、服务状态、生效日期、截止日期或长期有效。

只有数据库角色为 `SUPER_ADMIN` 的有效平台账号可以写入。普通平台账号只读，企业客服主管及坐席不能调用平台额度写接口。旧套餐修改接口不能绕过审计；管理员降权后已有登录令牌也会被拒绝。额度变更、操作者及前后快照在同一事务内保存，重复提交不重复加额。

每月基础额度重复生效，当月追加额度不结转；调整不会清零已使用数量。消息、AI、套餐功能、坐席和服务有效期均由服务端校验。企业侧“同事账号 → 套餐与用量”显示有效额度、已使用数量和截止日期。当前不包含支付、购买、扣款或续费订单流程。

- Web构建成功，最终本地容器已更新。静态分析没有error或warning，保留现有及未清理代码的info提示。
