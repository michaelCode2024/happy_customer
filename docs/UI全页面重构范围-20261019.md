## 实现入口与边界

- 网页客服端：`apps/agent_console/web/desktop.html`、`desktop/`、`mobile.html`、`mobile/`。
- 共享消息与身份逻辑：`mobile/core.js`、`mobile/messaging.js`、`mobile/message-actions.js`。
- 平台网页界面：`desktop/platform.js`，接口前缀 `/api/v1/platform`。
- Flutter 客户端界面：`apps/agent_console/lib/src/ui/`；实施时分别检查原生端和网页端，避免只改其中一层便声称全部完成。
- 访客组件：`packages/widget/src/`；独立消息与群聊入口另在 `apps/agent_console/web/`。
- 官网：`apps/website/`。
- 服务端页面与资源入口：`internal/server/static.go`。

客服接口前缀 `/api/v1/console`，主管管理接口前缀 `/api/v1/admin`，群聊接口前缀 `/api/v1/groups`。客服角色为 `SUPERVISOR` / `AGENT`，平台管理员权限单独判断；AI、群聊和自动化仍受现有能力开关约束。

当前主题来源 `web/mobile/workspace-theme.css`，主品牌蓝 `#3263ff`，正文 `#0c1d40`，页面底色 `#f5f7fb`。复用现有 `favicon.svg` / `logo.svg`、自定义图标和已有插画。

接待稿真实字段包括 `visitorId`、`inboxId`、`assigneeId`、`assigneeName`、`acceptedAt`、`createdAt`、`lastMessageAt`、`lastMessagePreview`、`agentUnread`、`tags`；客户资料使用 `externalId`、`attributes.phone`、`createdAt`；内部记录使用 `content`、`agentName`、`createdAt`。

不把 Stitch 自动扩写的 SLA、订单遥测、商业画像或工单等内容视为现有能力。新增接口或字段另行说明并取得用户同意。

设计正本保存在 Stitch。源码实现后分别验证真实渲染、断点、交互、权限和接口；构建通过不等于浏览器验收，浏览器验收也不等于手机安装与系统推送验收。
