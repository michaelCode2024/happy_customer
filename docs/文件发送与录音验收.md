# 文件发送与录音修复

2026-10-12，本地环境。

- 默认上传白名单补充WOFF、WOFF2、TTF、OTF字体类型。浏览器未提供字体MIME时，按已允许的字体扩展名兼容；部署者显式设置的白名单仍优先。字体作为附件下载，保留认证和文件大小限制。
- 访客端发送失败直接显示服务端原因，并保留原文件及重试流程。访客录音入口保持可见，不支持录音的浏览器明确提示安全访问地址及浏览器要求。
- 客服工作台增加“录制语音”：开始、停止、取消、最长120秒、添加语音及上传失败重试。添加后还需点击聊天发送按钮。关闭面板会释放音轨；麦克风授权超时或拒绝显示错误，迟到的授权音轨也会释放。
- 客服语音使用AUDIO消息类型并保留录音时长，失败重试保留时长和附件。沿用已有语音播放控件。

验证：Go全量测试通过；Flutter63项测试通过；访客组件16项测试通过；两端构建成功，Flutter分析没有error或warning。实际本地API对7600字节字体测试附件验证上传201、消息保存、下载200且字节一致；兼容默认二进制MIME的字体同样通过。1000毫秒WAV测试音频的上传、AUDIO消息及下载成功，时长保存正确。这里的字体与音频为合成测试数据，用于验证传输与消息链路。

实际浏览器验证客服可打开录音面板并查看字体及语音消息；自动化使用录音器替身验证停止、取消和上传失败重试。没有通过真实麦克风采集声音，实际设备录音仍需用户授权麦克风后试录。未部署生产。
