| --- | --- |
| 发送消息 | 客户和客服均通过浏览器输入、点击发送；无需刷新，对方收到消息 |

| 解散群聊 | 仅解散上述专用验收群，历史消息保留；发送输入和通话按钮停用，列表标为已解散，不能取消归档复活。其他示例群保留 |
| 发起语音 | 客户通过浏览器选择客服并呼叫，客服在工作台内嵌面板接听；双方进入「通话中」，计时正常 |
| 音频收发 | 最终版本读取 WebRTC 音频收发字节计数：客户 receivedBytes=18392、sentBytes=18381，客服 receivedBytes=20325、sentBytes=20343；两端 audio.readyState=4、paused=false，播放时间分别约5.90秒、6.07秒。这验证了本机两端媒体传输与播放，并非只验证信令；未进行人工听音质量评价 |
| 静音与挂断 | 客户和客服均验证静音按钮变化；客户挂断、客服挂断均使双端显示结束；结束后麦克风清理有专门自动化测试 |
| 来电与拒接 | 信令测试验证客户来电提示和拒接；真实来电验证客服工作台提示。通话面板已打开时不会叠加重复的全局来电弹窗 |
| 移动布局 | 390×844 浏览器视口，标题、通话/成员/设置按钮、消息、底部输入和发送均完整可见，未横向溢出 |

## 本轮多人音视频与平台登录（2026-10-11）

本地 `127.0.0.1:8080` 已启动新版。内部群与服务群提供群语音、群视频入口，最多 6 人；成员可加入、退出、静音和开关摄像头，发起人或群主可结束全场。视频房间允许不申请摄像头、仅语音加入。

### 真实浏览器证据

- 3 位独立群客户同时语音：每端连接另外 2 人，均实际发送、收到音频且媒体播放中。示例收/发音频字节：甲对乙 50600/51941，甲对丙 39414/40684；乙和丙也分别收到另外两端音频。证据 `group-multiparty-audio.json`。
- 静音及取消静音同步到其他成员；丙退出后其他两端继续通话，再加入恢复三端连接；发起人结束后各端释放媒体。
- 另建隔离的本地验收企业：客服 Flutter 工作台收到客户发起群语音的提示，点击「打开通话」进入内嵌面板；客服与 2 位客户同时连接。客服收/发音频：对丙 135317/139763，对乙 127000/133350，媒体持续播放。群主可结束客户发起的整场通话。证据 `group-mixed-audio.png`。
- 最终视频房间：客服与 2 位客户均取消摄像头勾选，3 端分别连接另外 2 人。音频继续传输，所有端视频收发字节为 0，显示「摄像头关闭」。证据 `group-video-camera-off.json/png`。**用户明确选择视频不启用摄像头，真实摄像头视频帧收发、摄像头开关的实际硬件效果未验收**。
- 关闭丙的浏览器页面后，心跳回收将参会人数恢复为2，其余两端继续连接；结束全场后所有端释放媒体。
- 手机宽度 390：页面 clientWidth/scrollWidth 均为390，通话面板高度574，采用2列成员卡片，无横向溢出。浏览器模拟尺寸，不代表物理手机/App验收。
- 平台管理员已保存登录恢复到运营概览；刷新仍在运营后台。客服同时登录独立验收账号后，平台标签页仍恢复平台运营后台。标签页入口及 `?surface=platform/agent` 分别生效。
