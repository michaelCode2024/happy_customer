二、按场景：打开哪几个
════════════════════════════════════

谈 SaaS 年费
  → 产品介绍及年度报价.pdf
  → 话术「金额确认」段
  → 需要可附带：服务方案说明.pdf

谈私有化 / 独立部署
  → 私有化部署方案及报价.pdf
  → 独立部署与平台授权说明.pdf

客户要「整包资料」
  → 只发 ZIP（见上一节第 3 / 4 份）
  → 话术「索要资料包」段

到账、开通、通知客户
  → 话术「已到账」「开通完成」
  → 超管账号（内部资料）进后台改套餐
  → 彩站账号说明是否与后台一致（见对下「改文案」）

客户要登录 / 对接密钥
  → 已打包客户：发该客户 ZIP，或单独发平台专属目录里的账号/对接文件
  → 彩站现成：对外资料/02_平台专属/caizhan/

改对外正文（改完要重生 PDF、再打包）
  → 只改同名 .txt（PDF 是生成物，不要手改 PDF）
  → 通用：对外资料/01_通用资料/…/*.txt
  → 彩站：对外资料/02_平台专属/caizhan/*.txt

════════════════════════════════════
四、别搞混的几条
════════════════════════════════════

1. 发给客户：优先 ZIP；临时单发用 PDF，不要把内部资料或本索引发出去。
2. TXT 与 PDF 成对：改 TXT → 跑 render 脚本出 PDF → 再 package；不要只改 PDF。
3. 彩站账号/密钥只在「02_平台专属/caizhan」及对应 ZIP；平台超管只在「内部资料」。
4. 仓库里其它 docs（使用指南、部署文档等）是工程说明，不是客户交付件；客户侧以「对外资料」为准。
