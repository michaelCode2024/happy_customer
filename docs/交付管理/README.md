# 客户交付管理

`对外资料/` 仅存放当前可交付内容。客户档案、开通模板、生成记录、话术和本文位于本目录，均不加入客户包。已被替代的对外文件直接删除，不复制到历史目录。客户正式资料正文不写日历日期与时间戳。

## 先看哪个

翻资料先开 [资料索引 · 哪些有用](资料索引/00_哪些有用.txt)：按谈价、发 ZIP、开通、查账号标出日常要用的文件；正式件仍在 `对外资料/`、`内部资料/`，本目录只做导航与流程。

## 新增客户与更新

为每家客户创建 `对外资料/02_平台专属/<slug>/`，只存该客户正式资料；创建 `docs/交付管理/客户/<slug>/客户档案.json` 管理其文件和凭证白名单。账号及密钥从该客户实际开通记录取得。

先更新 TXT，再执行 `python scripts/render-external-pdfs.py --platform <slug>` 生成 PDF。检查所有页面及凭证完整性后，执行 `powershell -File scripts/package-external.ps1 -Platform <slug>`。通用包省略 `-Platform`。

资料包采用固定文件名，重新生成时覆盖当前包且不保留备份；生成记录写入 `生成记录/<slug>.json`。通用资料和客户资料均按完整白名单检查，未登记的文件、内部信息及未完成的占位项会阻止打包。
