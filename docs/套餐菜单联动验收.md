# 套餐与企业菜单联动

> 历史专项记录：下文的实现和测试数量为原记录，不代表 2026-10-23 当前版本、线上部署或客户验收。本次审查只核对契约与文档，未重新执行这些历史测试；当前资料入口见 [文档索引](00-文档索引.md)。

平台管理员在「企业管理 → 企业详情 → 套餐」调整企业方案。企业客服工作台每 5 秒读取服务端权限，自动增减菜单；当前页面不在新的权限范围内时回到收件箱。平台超级管理员的运营菜单不受某一家企业的套餐限制。

| 套餐 | 企业菜单 |
| --- | --- |
| TRIAL 体验版 | 工作概览、收件箱、数据统计、知识库、个人设置、企业管理 |
| STARTER 专业版 | 体验版菜单，加群聊、应用接入 |
| GROWTH 旗舰版 | 专业版菜单，加自动回复、渠道管理；开放 AI 辅助接口 |
| ENTERPRISE 企业版 | 旗舰版菜单，加服务端访客身份票据接口 |

账号角色继续生效：企业管理、应用接入、自动回复、渠道管理仅限 SUPERVISOR，数据统计仅限 SUPERVISOR。购买套餐不会授予管理员身份。

服务端 `/api/v1/console/entitlements` 是菜单权限来源。群聊（含访客群聊）、自动回复配置、渠道会话管理、应用接入/Webhook/密钥、开放 API、AI 辅助接口在请求时重新检查套餐；已有密钥不能绕过降级。后台自动回复与 AI 自动回复也按套餐检查，降级保留配置但停止执行。

这里联动的是上述已存在模块的菜单和访问权限。套餐展示中的消息保留天数、参考价格、SLA、存储配额，以及消息编辑器内语音/回执等细粒度能力，不在本次菜单联动中新增收费或清理规则。

## 本地验收

- Go 服务端测试通过，包含四套餐能力矩阵和受保护路由映射。
- Flutter 44 项测试通过，静态分析无错误；HTML Web 构建通过。
- 独立测试企业在真实登录会话下：TRIAL 群聊/Webhook/自动回复均 403；STARTER 前两者 200、自动回复 403；GROWTH / ENTERPRISE 三者均 200。
- 浏览器保持登录，切换套餐后菜单随轮询更新，无需刷新。
- 浏览器在自动回复页面降级到体验版，受限菜单消失，并自动回到收件箱。
- 测试后独立企业及验收账号重新停用；日常企业套餐未调整。
